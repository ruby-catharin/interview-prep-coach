# Role Packs

The core skill is role-agnostic. A role pack adds the frameworks, seed questions, and rubric adjustments for one job family.

Included:
- `product-management.md`: PM, Senior PM, Technical PM, AI PM

## No pack for the target role?
Build a temporary one in the conversation (save it here if the user wants to keep it). Cover:
1. **Frameworks** strong candidates in this role use, e.g. system design for engineering, portfolio critique for design, a sales methodology for AEs, case structuring for consulting.
2. **Round types** typical for the role and level.
3. **Seed questions**: 3–5 per round type.
4. **Rubric adjustments**: what caps a dimension for this role (e.g. engineering with no complexity analysis → Substance ≤ 7).

Name sources for any company- or industry-specific practice, and say when you're unsure.
